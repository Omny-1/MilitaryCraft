============================================================
  MilitaryCraft resource pack - 3D models for the equipment
  Minecraft 1.21.4
============================================================

This pack gives the 38 infantry equipment items their custom 3D models. The
models are complete and are built from vanilla block textures, so the pack
carries no image or sound files and needs no external assets.

IMPORTANT: the pack is not optional for appearance.

The plugin writes an item_model reference into every equipment item when the
item is created, and it does so unconditionally. There is no configuration
switch that turns this off. A player without the pack will therefore see the
missing-model placeholder instead of the intended model. The items still work
exactly as documented, and every command, permission and effect behaves the
same way; only the rendering differs.

------------------------------------------------------------
STRUCTURE
------------------------------------------------------------

  pack.mcmeta
  assets/warkit/items/<id>.json         item_model mapping for warkit:<id>
  assets/warkit/models/item/<id>.json   the 3D model itself

The warkit namespace is the identifier the plugin writes into items. It is
kept as it is because changing it would break the appearance of every item
that players are already carrying on running servers.

Item ids, 38 in total:

  Medical and consumable
    medkit, painkiller, ration, combat_stim, repair_kit

  Armour and wearables
    vest, kevlar_helmet, exosuit, gas_mask, pads, camo_cloak, visor_helmet

  Firearms
    rifle, pistol, grenade_launcher, patriot, maxim, flamethrower,
    chemical_sprayer

  Thrown
    frag_grenade, smoke_grenade, flash_grenade, impulse_grenade, molotov,
    sleep_gas

  Deployable and traps
    barbed_wire, tripwire_trap, proximity_mine, sentry_gun, firing_wall,
    c4, suicide_vest

  Utility
    marker, grappling_hook, jump_jet, recon_scanner, trench_shovel

  Other modules
    airstrike_beacon

------------------------------------------------------------
STEP 1. BUILD THE ARCHIVE
------------------------------------------------------------

Archive the contents of this directory. pack.mcmeta and the assets directory
must sit at the root of the zip, not inside an extra folder. Name it whatever
you like, for example MilitaryCraft.zip.

Do not zip the parent directory. If the archive opens to a single folder that
then contains pack.mcmeta, Minecraft will not recognise it as a pack.

------------------------------------------------------------
STEP 2. DISTRIBUTE IT
------------------------------------------------------------

Option A, served by the server:

  1. Upload the zip to a direct download address.
  2. In server.properties:

       resource-pack=DIRECT_ZIP_URL
       resource-pack-sha1=<sha1 of the file>
       require-resource-pack=false

     Set require-resource-pack to true if players must accept it. Because the
     models are applied unconditionally, true is the setting that matches how
     the plugin behaves.

     On Windows the hash is produced with:

       certutil -hashfile MilitaryCraft.zip SHA1

  3. Restart the server.

Option B, installed locally:

  Place the zip in .minecraft/resourcepacks and enable it in the game.

------------------------------------------------------------
STEP 3. MODIFYING A MODEL
------------------------------------------------------------

Open the model in Blockbench using the Java Block/Item format, edit it, and
export it back over assets/warkit/models/item/<id>.json. Leave the matching
file in assets/warkit/items/ alone; it only points at the model.

Items already in player inventories keep working after a model change. The
reference written into the item is the id, not the geometry, so a rebuilt pack
updates the appearance of existing items as soon as it is loaded.
