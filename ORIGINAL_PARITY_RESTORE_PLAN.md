# MilitaryCraft Original-Parity Restore Plan

Last updated: 2026-07-15

## Goal

Restore every merged MilitaryCraft module so it behaves like its original standalone plugin, with only the minimum adaptation needed for the unified `MilitaryCraft` jar. The original plugin source/config/data is the source of truth. No module is marked done until it passes a detailed parity review against the original.

## Non-Negotiable Rules

- Do not redesign mechanics, models, hitboxes, items, controls, effects, or balancing unless the user explicitly asks.
- Prefer a direct source port of the original classes over a new abstraction.
- Keep unified plugin wiring only where required: module enable/disable, namespaced keys, `/mc` command access, shared jar packaging.
- Preserve original model geometry, Display/Interaction layout, hitbox dimensions/offsets, seats, pivots, materials, item names/lore/model data intent, config defaults, cooldowns, damage, particles, sounds, commands, permissions, GUIs, persistence, and cleanup semantics.
- Preserve server-side data/config behaviour from `F:\program\server 1 21 4\plugins\<PluginName>` where present.
- After each module restore: run compile/tests, compare source constants and behaviour against the original, update this file, then move to the next module.

## Review Checklist Required Before Marking Any Plugin Done

- [x] Source map: every original Java/config/resource file has a matching port or documented reason.
- [x] Commands/permissions: original command names, aliases, arguments, tab-complete behaviour, messages, and permissions are preserved or exposed through `/mc` without losing behaviour.
- [x] Items/resources: original materials, CustomModelData, names, lore, tags, recipes/resourcepack files where applicable.
- [x] Model: original part list, dimensions, rotations, pivots, materials, interpolation, transformations and visual layout.
- [x] Hitboxes/seats: original Interaction/ArmorStand hitbox count, width, height, offsets, seat/camera positions, passenger seats.
- [x] Mechanics: movement, weapons, AI, targeting, cooldowns, damage, explosions, block interaction, physics and effects.
- [x] Config/data: original defaults and live server data/config are supported.
- [x] Persistence/cleanup: original entity tags/PDC/data files, reload behaviour, world/chunk cleanup and shutdown semantics.
- [x] Regression check: `mvn -o test` and `mvn -o -DskipTests package` pass.
- [x] Manual review note: exact deviations list is empty or explicitly approved by the user.
